# PasswordGenerator
This is a simple Python-based password generator that allows users to create strong, random passwords with a customizable length.
The generated passwords include a mix of uppercase and lowercase letters, numbers, and special characters to enhance security.

Features:
User input for desired password length

Randomized mix of:
Letters (uppercase & lowercase)
Numbers
Special characters

Simple and easy to use via the command line

How to Use:
Run the script.
Enter the number of characters you want in your password.
Get a secure, randomly generated password instantly.
